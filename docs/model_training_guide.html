TinyML Model Training Guide (with Edge Impulse)

This guide walks you through building, training, and deploying your forest acoustic surveillance classification model using Edge Impulse.

Step 1: Create an Edge Impulse Project

  1. Sign up for a free developer account at Edge Impulse.
  2. Create a new project named Forest-Acoustic-Surveillance.
  3. Select Audio as your data type.

Step 2: Upload Your Preprocessed Dataset

Use the files you formatted using data_prep/format_audio.py (which are in 16kHz, 16-bit, Mono WAV format).

  1. In the Edge Impulse Studio, go to Data Acquisition.
  2. Click Upload existing data.
  3. Choose your audio files.
  4. Set the label automatically based on the folder/file name (e.g., chainsaw, gunshot, axe, footsteps, ambient).
  5. Choose Automatically split between training and testing (keeps an 80/20 train/test split).

Step 3: Design Your Impulse

An Impulse is the machine learning pipeline (features -> processing block -> learning block).

  1. Go to Impulse Design.
  2. Set the window size to 2000 ms (2 seconds) and the window increase to 500 ms.
  3. Add a Processing Block: Select Audio (MFE) (Mel-Frequency Energy) or MFCC.
  4. MFE is better for non-voice environmental sounds like chainsaws, gunshots, and engines.
  5. MFCC is better for human voice/speech detection.
  6. Add a Learning Block: Select Classification (Keras).
  7. Click Save Impulse.

Step 4: Extract Features

  1. Go to MFE / MFCC in the sidebar.
  2. Under parameters, leave the default settings:
  3. Frame length: 0.02s (20 ms)
  4. Frame stride: 0.01s (10 ms)
  5. Number of Mel filters: 40
  6. Click Save parameters.
  7. Click Generate Features. Edge Impulse will convert all your 2-second audio clips into feature vectors and display them in a 3D visualization. Ensure different classes are clustered separately.

Step 5: Train the Neural Network

  1. Go to Classifier in the sidebar.
  2. Configure the training settings:
  3. Number of epochs: 50 to 100
  4. Learning rate: 0.005
  5. Validation set size: 20%
  6. Use a 2D Convolutional Neural Network (CNN) architecture (Edge Impulse provides a pre-configured 2D CNN optimized for audio).
  7. Click Start Training.
  8. Once complete, review the Accuracy and Confusion Matrix. Target an accuracy of > 90%.

Step 6: Quantize and Export to ESP32-S3

To run the model on a microcontroller, we must quantize it to INT8 (which reduces model size by 75% and speeds up inference with negligible accuracy loss).

  1. Go to Deployment in the sidebar.
  2. Under "Select deployment", choose Arduino Library (or C++ Library if using ESP-IDF).
  3. Under "Select optimizations", select Quantized (int8).
  4. Click Build.
  5. A ZIP file containing the C++ library will download.
  6. In Arduino IDE: Go to Sketch -> Include Library -> Add .ZIP Library... and select the downloaded file.
  7. Include the library headers in your firmware.ino sketch and run the inference using the API generated by Edge Impulse.
