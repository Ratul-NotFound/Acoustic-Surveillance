# Thesis Reference: Acoustic Datasets Index

This document provides a clean index of the primary public acoustic datasets used for training and validating your forest surveillance AI model. You can copy these links directly into your thesis bibliography or literature review chapter.

---

## 1. Primary Forest & Threat Datasets

| Dataset Name | Primary Threat Classes Included | Download Link (URL) |
| :--- | :--- | :--- |
| **FSC22 (Forest Sound Classification Dataset)** | Chainsaws, Axes, Handsaws, Tree Falling, Rain, Wind, Thunder, Animals | [Kaggle - FSC22 Dataset](https://www.kaggle.com/datasets/dakshinaranmal/fsc22-v1) |
| **Tropical Forest Gunshot Classification Dataset** | Gunshots (pistol, rifle, shotgun), Jungle Ambient Noise, Forest Weather | [Mendeley Data - Gunshot Dataset](https://data.mendeley.com/datasets/x48cwz364j/3) |
| **Environmental Audio Recordings (Chainsaw)** | Chainsaw engine operation, idling, mechanical noise | [Zenodo - Chainsaw Dataset](https://zenodo.org/records/5824905) |
| **Rainforest Connection (RFCx) Dataset** | Tropical rainforest soundscapes, birds, monkeys, cicadas, rain | [Kaggle - Rainforest Connection Species Detection](https://www.kaggle.com/competitions/rfcx-species-audio-detection) |

## 4. Citation and Reference Format for Your Bibliography

When referencing these datasets in your thesis report, you can use the following standard citation formats:

*   **FSC22**:
    > *Dakshinaranmal, S. (2022). FSC22: A Forest Sound Classification Dataset for Illegal Logging Detection. Kaggle. https://www.kaggle.com/datasets/dakshinaranmal/fsc22-v1*
*   **Tropical Forest Gunshot**:
    > *Mendeley Data. (2020). Tropical Forest Gunshot Classification Dataset. Mendeley. https://data.mendeley.com/datasets/x48cwz364j/3*
*   **ESC-50**:
    > *Piczak, K. J. (2015). ESC: Dataset for Environmental Sound Classification. GitHub. https://github.com/karoldvl/paper-2015-esc-dataset*
